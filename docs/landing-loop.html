01 · trusted execution

No more step-by-step approvals

Three presets cover most cases out of the box, enforced by an OS-level sandbox and glob-based rules. Set the rules, and the agent runs unattended — overnight refactors, bulk lint fixes, PR auto-review — without you watching, without going off the rails.

  • safe — read-only, CI/CD auto-review
  • default — workspace writable, dev work
  • risk — full access, migrations
  • escape hatch — most-specific rule wins, so a narrow allowWrite can open up any preset
security presetsrules.py + sandbox.py
presetreadwritecommands
safeglobalblockedblocked
defaultglobalworkspace + /tmpwhitelisted
riskglobalglobalall
# secrets are hard-blocked on every preset:
#   .ssh/  .aws/  .gnupg/  .env

# carve out writes on top of safe — config.json:
{ "preset": "safe",
  "rules": { "allowWrite": ["./reports/**"] } }
02 · agentcard

One Markdown file is one agent

Define ready-to-use specialists — tools, MCP servers, skills, permissions — in a single card, then run them with --as. No code, no framework — just a card and a flag.

  • built-in — Explore / Plan / Review / SetupZed ship in the box
  • custom — drop agents/MyAgent.md in your repo
  • override — project cards shadow built-ins by name
  • hooks — onAgentStart / onAgentEnd scripts chain agents deterministically
agents/Refactorer.mdyaml + markdown
---
name: Refactorer
description: Async-refactoring specialist
tools: [Read, Edit, Grep, Glob]
mcp_servers: [playwright]
skills: [refactor]
preset: default
---

You refactor code to async. Never touch tests.

$ letscode --as Refactorer "extract UserService from app.py"
03 · acp

Need an interactive session? Plug into your editor

LetsCode speaks the Agent Client Protocol — the open standard adopted by Zed and a growing ecosystem of editors. One server, any compatible client, zero lock-in.

  • SetupZed — built-in agent writes .zed/settings.json for you
  • sessions — persist across restarts: list / load / resume
  • context — /compact · /new · /undo built in
  • usage — per-turn token footer with cache hit rate
shelleditor setup
# Zed — built-in agent writes the config for you
$ letscode --as SetupZed

# JetBrains
$ letscode --as SetupJetbrains

# or run the ACP server directly (stdio)
$ letscode-acp -c config.json
04 · multi-agent

Compose agents like Unix tools

AgentCards define the roles; the shell does the orchestration. Chain specialists with pipes, or let the main agent delegate sub-agents itself — any workflow you can imagine, Unix-style.

  • pipe-friendly — --event-stream emits structured JSONL
  • sub-agents — spawn workers so the main context stays clean
  • deterministic hooks — shell scripts decide what runs next, not vibes
  • no new framework — no SDK, no control plane. It's just shell
⌕ Explore
✎ Plan
✓ Review
JSONL events flow downstream — like any other Unix pipe
$ letscode --as Explore "find all async funcs" --event-stream \
    | letscode --as Plan "draft refactoring plan" --event-stream \
    | letscode --as Review "review the plan"

Small harness, complete toolbox

Everything a coding agent needs to work a full day unattended — and nothing it doesn't.

cli the core loop

Any LLM

GLM / DeepSeek / Qwen / GPT / local models — anything OpenAI-compatible, plug and play.

Vision proxy

Text-only models handle images too — set a vision_model and images are auto-routed and described in text.

OS-level sandbox

macOS Seatbelt profiles, three presets: safe / default / risk. Secrets always blocked.

MCP

Connect stdio / HTTP / SSE servers — tools auto-discovered and merged into the loop.

Skills

Your team's commit / review workflow as a SKILL.md, invoked with a single command.

Sub-agents

Delegate searches and sub-tasks to spawned agents so the main context stays clean.

Workspace-aware

--workspace switches cwd; logs, sandbox bounds and env context bind automatically.

Project rules

Follows the AGENTS.md convention — coding standards take effect automatically.

JSON event stream

--event-stream emits structured JSONL — pipe-friendly, replay-friendly.

Usage stats

Running in five minutes

No build step, no daemon, no account. Install, paste a key, go.

1

Install

$ curl -fsSL https://raw.githubusercontent.com/letscan/letscode/main/scripts/install.sh | sh
# installs uv if missing, then letscode
2

Configure

$ cp config.example.json config.json
$ # add your API key

# or skip the file entirely:
$ export OPENAI_API_KEY="..."
3

Run

$ letscode "add a /health endpoint to app.py"

# or give it the night shift:
$ letscode --preset default \
    "refactor auth/ to async"
