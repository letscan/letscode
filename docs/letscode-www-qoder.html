Why LetsCode

Automation you can actually leave running

No more step-by-step approvals. Set the rules once and the agent works unattended — overnight refactors, bulk lint fixes, PR auto-review — without going off the rails.

True automation, trusted execution

Three security presets cover most cases out of the box, enforced by an OS-level sandbox (macOS Seatbelt) — not just prompt promises. Need finer control? Custom rules in config.json tighten or open up any preset, with most-specific-wins resolution.

Secret paths (.ssh/ .aws/ .gnupg/ .env) are blocked on every preset. No exceptions.
--preset saferead-only
Global read, writes blocked, commands blocked. CI/CD auto-review, audits.
$ letscode --preset safe "review PR #142"
--preset defaultworkspace
Workspace + /tmp writable, whitelisted commands. Overnight refactors.
$ letscode --preset default "refactor auth/ to async"
--preset riskfull access
Global read/write, all commands. Full migrations — secrets still denied.
$ letscode --preset risk "migrate db schema to v2"

AgentCard — an agent is a file

Define a ready-to-run agent — tools, MCP servers, skills, permissions — in one Markdown file, then run it with --as. No code, no framework. Just a card and a flag.

  • Project cards in agents/<Name>.md override built-ins
  • --list-agents shows every available card
  • Lifecycle hooks: onAgentStart / onAgentEnd shell scripts for orchestration

Ships built-in: Explore · Plan · Review · SetupZed · DevHard · Worker · Tester

agents/Refactorer.md
---
name: Refactorer
tools: [Read, Edit, Grep, Glob]
mcp_servers: [playwright]
skills: [refactor]
preset: default
---
You are a refactoring specialist…
# run it:
$ letscode --as Refactorer "extract a UserService from app.py"

Composable, Unix-style

Chain agents at the shell with --event-stream JSONL output — pipe-friendly by design. Or let the main agent spawn sub-agents itself so the primary context stays clean.

  • Any workflow you can imagine, built from cards and pipes
  • DevHard orchestrator judges pass/fail by exit codes, not LLM self-reports
Explorefind async funcs
Plandraft the plan
Reviewreview the plan
$ letscode --as Explore --event-stream "find all async funcs" \
| letscode --as Plan --event-stream "draft refactoring plan" \
| letscode --as Review "review the plan"

# or just: letscode "refactor src/ for async — delegate as needed"

Plugs into your editor

Need an interactive session? LetsCode speaks the Agent Client Protocol — the open standard adopted by Zed and a growing ecosystem of editors. One server, any compatible client, zero lock-in.

Built-in ACP serverletscode-acp over stdio — any compatible editor plugs right in.
Sessions that survive restartsList, load, resume — your history persists on disk.
Context management/compact LLM-summarized compression · /new reset · /undo rollback.

# JetBrains
$ letscode --as SetupJetbrains

Features

Small core. Sharp edges.

Everything a harness needs, nothing it doesn't. Each capability is a flag, a file, or a line of config.

Any LLM

Any OpenAI-compatible API — GLM, DeepSeek, Qwen, GPT, Gemini, local models. One JSON config.

Vision proxy

Text-only main model? Set a vision_model and images are auto-routed and described in text.

OS-level sandbox

macOS Seatbelt profiles on every Bash subprocess — safe / default / risk.

MCP

Connect stdio / HTTP / SSE MCP servers; tools are auto-discovered and merged into the loop.

Skills

Your team's commit / review workflow as a SKILL.md — invoke it with a single command.

Sub-agents

Delegate searches and sub-tasks to spawned agents so the main context stays clean.

Workspace-aware

--workspace binds logs, sandbox boundaries, and env context (cwd / git / platform) automatically.

AGENTS.md rules

Follows the AGENTS.md convention — coding standards take effect automatically.

JSON event stream

--event-stream emits structured JSONL — pipe-friendly, IDE-friendly, replay-friendly.

Usage stats

Per-turn token footer with cache hit rate — 2.7k tokens (99%cached).

IDE-integrated ACP

letscode-acp ships a stdio ACP server; any compatible editor plugs right in.

Sessions & context ACP

Sessions persist across restarts. /compact · /new · /undo manage context.

Quick start

From curl to shipping in three steps

01 / INSTALL

One-liner

Installs uv if missing, then LetsCode as a global tool.

$ curl -fsSL https://raw.githubusercontent.com/
letscan/letscode/main/scripts/install.sh | sh
02 / CONFIGURE

Point it at any LLM

Copy the template, drop in an API key. Env vars override everything.

$ cp config.example.json config.json
# { "default_model": "glm-5-turbo",
# "providers": { "zhipu": { "api_key": "…" } } }
03 / RUN

Say what you want

The loop handles the rest — LLM → tools → feedback, until done.

$ letscode "add a /health endpoint to app.py"
✓ Done — 3 turns · 4 tool calls

Requires Python 3.11+ · or clone & uv tool install git+https://github.com/letscan/letscode.git
