01 · 真正的自动化，放心执行 01 · TRUE AUTOMATION, TRUSTED EXECUTION

告别逐条审批 No more step-by-step approvals

三档预设覆盖大多数场景——safe 只读审查、default 工作区开发、risk 完全权限。规则定好，Agent 自主跑完全程：CI 自动审查、夜间重构、批量修 lint——你不在场，它也不会闯祸。不够用？自定义规则在任意预设上精确放开或收紧。 Three presets cover most cases: safe (read-only, CI/CD review), default (workspace writable, dev work), risk (full access, migrations). Set the rules, and the agent runs unattended — overnight refactors, bulk lint fixes, PR auto-review — without you watching, without going off the rails. Need finer control? Custom rules tighten or open up any preset.

  • safe · 只读，CI/CD 自动审查safe · read-only, CI/CD auto-review
  • default · 工作区可写，日常开发default · workspace writable, dev work
  • risk · 完全权限，全量迁移risk · full access, migrations
  • 高级 · 在 safe 基础上精确放开写入advanced · open up writes on top of safe
shellpresets
# safe — 只读，CI/CD 自动审查
$ letscode --preset safe "review PR #142"

# default — 工作区可写，夜间重构
$ letscode --preset default "refactor auth/ to async"

# risk — 完全权限，全量迁移
$ letscode --preset risk "migrate db schema to v2"

# 高级 — safe 基础上放开 reports/ 写入
# config.json: { "preset":"safe",
#   "rules": { "allowWrite": ["./reports/**"] } }
$ letscode --preset safe "generate coverage report"
02 · AGENTCARD · 按需定制，即定即跑 02 · AGENTCARD · TAILOR AND RUN

定义完备、随手可用的 Agent Define ready-to-use agents

一个 Markdown 文件，声明一个完整 Agent——它能用什么工具、连哪些 MCP、带哪些技能、有什么权限。--as 一行调用，不用写代码，不用学框架。内置 Explore / Plan / Review / SetupZed 四张卡。 One Markdown file declares a complete agent — its tools, MCP servers, skills, and permissions. Run it with --as. No code, no framework — just a card and a flag. Ships four built-in cards (Explore / Plan / Review / SetupZed).

  • 内置卡 · --as Review 直接跑Built-in · --as Review ready to go
  • 自定义 · agents/MyAgent.md，一个文件搞定Custom · agents/MyAgent.md, one file done
  • 定义 · tools + MCP + skills + preset + rulesDefine · tools + MCP + skills + preset + rules
  • 覆盖 · 项目级同名卡覆盖内置卡Override · project cards override built-ins
shell--as
# 用内置卡
$ letscode --as Review "review tools/runner.py"

# 列出所有可用卡
$ letscode --list-agents

# 你的自定义卡 (agents/Refactorer.md)
# ---
# name: Refactorer
# tools: [Read, Edit, Grep, Glob]
# mcp_servers: [playwright]
# skills: [refactor]
# preset: default
# ---
$ letscode --as Refactorer "extract UserService from app.py"

无论是 AgentTeam 还是动态 Workflow AgentTeam, dynamic workflows, and beyond

AgentCard 定义角色，CLI 原生组合——像搭 Unix 工具一样，构造你能想到的任何 Agent 工作流。 Define roles with AgentCards, compose them at the shell — build any agent workflow you can imagine, Unix-style.

  • AgentCard 即角色 · 一个 Markdown 定义一个专家 AgentCards as roles · one Markdown file per specialist agent
  • Agent 工具内置委托 · 主 Agent 自主 spawn 子 Agent 并行干活Built-in delegation · the main agent spawns sub-agents in parallel
  • 管道串联 · --event-stream JSONL 输出，shell 管道自由组合Pipe-friendly · --event-stream JSONL output, chain at the shell

shellmulti-agent workflow
# Explore 搜代码 → Plan 出方案 → Review 审查
$ letscode --as Explore "find all async funcs" \
    --event-stream | letscode --as Plan "draft refactoring plan" \
    --event-stream | letscode --as Review "review the plan"

# 或者让主 Agent 自主委托子 Agent
$ letscode "refactor src/ for async — delegate as needed"

▸ Agent: Plan (drafting step-by-step…)
